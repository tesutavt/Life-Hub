# Формат курса-тренировки `lifehub-course@1`

Курс-тренировка — это JSON-файл, который импортируется во вкладке **Курсы → Курсы-тренировки → Импорт курса**.
После импорта получаются уроки в стиле Duolingo: карточки «запомни слово», выбор перевода, ввод перевода,
сопоставление пар, сборка фразы из плиток, заполнение пропуска и аудирование (озвучка через Web Speech API).

Готовый промпт для нейросети и пример курса есть прямо в приложении: кнопка **«Шаблон для ИИ»**
(тот же текст отдаёт `GET /api/learn/template`).

## Связь с остальным приложением

- При импорте курс по умолчанию добавляется в список **«Курсы»**. Его прогресс считается автоматически:
  пройденные уроки + отмеченные учебные материалы. Привязку можно поменять в редактировании курса
  (поле «Курс-тренировка»).
- Если у курса выбран язык, этот прогресс входит в общий прогресс языка (среднее по курсам языка),
  слова пройденных уроков попадают в словарь (SRS), а занятия засчитываются в стрик и дневную цель языка.
- Прохождение уроков даёт XP и засчитывается в ачивках (действия категории «Обучение»).

## Структура

```jsonc
{
  "format": "lifehub-course@1",
  "title": "Японский: первые шаги",          // обязательно
  "description": "Приветствия и базовые слова",
  "from_language": "ru",                      // язык объяснений (ISO 639-1)
  "to_language": "ja",                        // изучаемый язык
  "speech_lang": "ja-JP",                     // язык озвучки (BCP-47); без него аудирование выключено
  "icon": "🇯🇵",
  "color": "#58cc02",
  "units": [                                  // разделы, обязательно хотя бы один
    {
      "title": "Раздел 1. Знакомство",
      "description": "Здороваемся и прощаемся",
      "color": "#58cc02",
      "guide": "Короткий справочник по грамматике раздела",
      "lessons": [                            // уроки открываются по порядку
        {
          "title": "Урок 1. Приветствия",
          "description": "Здравствуйте, доброе утро",
          "xp": 10,                           // 1–100, по умолчанию 10
          "words": [ /* слова, см. ниже */ ],
          "exercises": [ /* упражнения, см. ниже; можно не указывать */ ]
        }
      ]
    }
  ]
}
```

### Слово

| Поле | Обяз. | Описание |
|---|---|---|
| `term` | да | слово на изучаемом языке |
| `translation` | да | перевод |
| `reading` | | транскрипция / латиница (для японского, китайского и т.п.) |
| `emoji` | | картинка-эмодзи на карточке |
| `note` | | подсказка |
| `example`, `example_translation` | | пример употребления |
| `alternatives` | | другие допустимые переводы (засчитываются при вводе) |
| `audio` | | своя запись произношения: `https://…/word.mp3` или `/uploads/…` |

### Упражнения

| `type` | Поля | Что делает пользователь |
|---|---|---|
| `theory` | `title`, `text` | читает правило |
| `learn` | `word` — `term` из `words` | запоминает новое слово (карточка) |
| `choice` | `prompt`, `question`, `options[]`, `answer` | выбирает правильный вариант |
| `translate` | `prompt`, `answers[]`, `direction` (`to_native` / `to_target`), `hint` | вводит перевод |
| `match` | `pairs: [["term","перевод"], …]` (2–8 пар) | соединяет пары |
| `assemble` | `prompt`, `answer` (слова через пробел), `tokens[]` — лишние плитки | собирает фразу из плиток |
| `fill` | `sentence` с `___`, `answer`, `options[]` (необяз.), `translation` | заполняет пропуск |
| `listen` | `text`, `answers[]` | слушает и записывает |

Правила проверки: регистр, `ё/е`, знаки препинания и лишние пробелы игнорируются; в ответах длиннее
4 символов одна опечатка засчитывается. Ошибочное задание повторяется в конце урока, на урок даётся
5 сердечек. Повторное прохождение даёт половину XP, урок без ошибок — +5 XP.

Если `exercises` не указаны, приложение сгенерирует их из `words` само: карточки, выбор перевода,
сопоставление, перевод в обе стороны и аудирование (если задан `speech_lang`). Слова, у которых нет
карточки `learn`, автоматически показываются перед первым упражнением.

### Озвучка

Аудиофайлы в курсе не обязательны. Кнопка 🔊, карточки слов и упражнения `listen` берут звук так:

1. `audio` слова, если указан;
2. сервер Life Hub (`GET /api/tts?text=…&lang=ja-JP`) — скачивает mp3 один раз и кладёт в кэш
   (`server/tts-cache`, в десктоп-версии — `%APPDATA%/Life Hub/tts-cache`), дальше звук играет мгновенно и без интернета.
   Одиночные знаки каны с `reading` (например, `あ` + `a`) берутся из живых записей, как в тренажёре каны,
   остальное — онлайн-синтез Google Translate;
3. если сервер недоступен — синтезатор речи браузера/Windows (для японского нужен установленный японский голос).

Язык озвучки задаётся полем `speech_lang` курса.

### Ограничения

до 100 разделов, до 100 уроков в разделе, до 80 слов и 80 упражнений в уроке, файл до 10 МБ.
Некорректные упражнения при импорте пропускаются; пустой урок (без слов и упражнений) — ошибка импорта
с указанием раздела и номера урока. Ответ нейросети в обёртке ```` ```json ```` вставлять можно — она срезается.
