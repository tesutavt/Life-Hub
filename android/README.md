# Life Hub для Android

Нативное приложение на Kotlin + Jetpack Compose. Работает с тем же сервером, что веб- и
десктоп-версии (см. `deploy/README.md`): при первом запуске укажите IP или домен сервера.

## Что есть в приложении

| Раздел | Возможности |
|---|---|
| Подключение и вход | выбор сервера по IP/домену с проверкой, недавние серверы, вход, регистрация |
| Главная | уровень и XP, серия, задания дня, «Продолжить обучение», привычки на сегодня, настроение, быстрые разделы |
| Учёба | языки (цель дня, серия), словарь с поиском и добавлением слов, тренировка слов (SRS) |
| Курсы-тренировки | дорожка уроков как в Duolingo, справочник раздела, плеер уроков: 8 типов упражнений, сердечки, повтор ошибок, озвучка, звуки и вибрация |
| Задания | ежедневные (забрать награду) и задания недели |
| Привычки | отметки за 7 дней, добавление, удаление (долгое нажатие) |
| Профиль | баннер, аватар, уровень, карта активности, витрина ачивок |
| Ачивки | все ачивки с прогрессом и фильтрами; всплывающее уведомление о новой |
| Календарь | месяц со сменами/учёбой/настроением, события дня, добавление и удаление |
| Цели на год | прогресс, отметка «+1 сегодня», создание |
| Напоминания | смешные уведомления от совы Хаби (как в Duolingo): урок не пройден, серия в опасности, привычки, календарь, задания, цели; новые ачивки, когда приложение закрыто. Нажатие открывает нужный раздел |
| Настройки | напоминания (всё / по категориям / время / «не беспокоить»), уведомления на этом телефоне, смена сервера, выход |

Редактор страниц, финансы и импорт выписок, отчёты, соцсети/Twitch, импорт курсов и админка
пока открываются в веб-версии (Настройки → «Открыть веб-версию»).

## Сборка

Нужны JDK 17+ и Android SDK (у вас: `H:\Programs\Android\sdk`, путь задан в `local.properties`).

```powershell
cd android
$env:GRADLE_USER_HOME = "H:\Programs\Android\gradle-home"
.\gradlew.bat assembleRelease      # → app\build\outputs\apk\release\app-release.apk  (~2 МБ)
.\gradlew.bat assembleDebug        # → app\build\outputs\apk\debug\app-debug.apk
.\gradlew.bat testDebugUnitTest    # проверка, что модели читают реальные ответы сервера
```

Установка на телефон: скопируйте APK и откройте его (разрешите установку из неизвестных источников)
или по USB с включённой отладкой: `H:\Programs\Android\sdk\platform-tools\adb.exe install -r app-release.apk`.

## Подпись релиза

Сейчас релиз подписывается debug-ключом (`%USERPROFILE%\.android\debug.keystore`) — APK ставится,
но для публикации в магазинах нужен свой ключ:

```powershell
keytool -genkeypair -v -keystore lifehub.keystore -alias lifehub -keyalg RSA -keysize 2048 -validity 10000
```

и блок `signingConfigs { create("release") { … } }` в `app/build.gradle.kts`.
Обновления ставятся поверх только при подписи тем же ключом — храните keystore.

## Напоминания

WorkManager раз в 15 минут спрашивает сервер (`GET /api/reminders/pending`) с локальными датой и часом
телефона. Тексты и правила «когда напоминать» живут на сервере (`server/routes/reminders`, `server/reminders/messages.js`) —
одинаковые для телефона и компьютера. Каждая категория — отдельный канал уведомлений Android.

## HTTP и HTTPS

Чтобы подключаться к серверу по `http://IP:4000`, приложению разрешён незашифрованный трафик
(`res/xml/network_security_config.xml`). С доменом и HTTPS всё работает без изменений.
